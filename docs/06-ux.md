# 6. UX и макеты

Макеты собирает **Figma-плагин** [`figma-plugin/`](../figma-plugin) — полноценный UI Kit:
переменные, стили текста, 75 компонентов с вариантами и четыре экрана на auto-layout.
Превью всех страниц — в [`figma-plugin/preview/`](../figma-plugin/preview).

**Откуда дизайн.** Устройство кита взято у генератора «ФОЛК»: примитивы → токены → размеры,
компоненты с вариантами, страницы «Основы / Компоненты / Экраны». Визуальный язык — у дашборда
деградаций сервисов: белая страница без бокового меню, чёрный текст, тонкие линии, белые «таблетки»
с мягкой тенью, серые подложки, шкала зелёный → жёлтый → оранжевый → красный, ячейки «тон / цвет».
Мониторинг казначейства — та же предметная область (сервис → деградация → инцидент), поэтому
пользователь «Диво» встречает знакомые приёмы.

| Экран | Для кого | Задача пользователя |
|---|---|---|
| **01 · Мониторинг событий** | дежурная смена (1-я линия) | за 5 секунд понять, что горит, и что спасать первым |
| **02 · Карточка события** | 1-я и 2-я линия | понять, что случилось, сколько времени до нарушения SLA, кто уже работает |
| **03 · Дашборд «Диво Мера»** | владелец услуги, руководство | доступность и SLA за месяц, где события копятся систематически |
| **04 · Виджет «Диво Портал»** | сотрудники бэк-офиса казначейства | узнать, что о сбое уже знают, — не звонить в поддержку |

## 6.1. Мониторинг событий

![Мониторинг событий](../figma-plugin/preview/01-Мониторинг-событий.png)

* Справа от заголовка — **статус интеграции** (heartbeat, очередь, DLQ): тишина в списке — норма,
  только если интеграция жива.
* Четыре показателя: активные события, **SLA под угрозой**, открытые инциденты, время обнаружения.
* **Таблица событий** из шести колонок: критичность первой, отклонение в понятных единицах
  («+173 %, 27 из 10 мин»), SLA — запас времени («осталось 22 мин»), устранённые приглушены.
* Похожие события сгруппированы по `correlationKey`: один сбой — одна строка.

## 6.2. Карточка события

![Карточка события](../figma-plugin/preview/02-Карточка-события.png)

* Крупно — **сколько осталось до нарушения SLA**, под ним шкала «старт → норматив → сейчас → дедлайн».
* **Что произошло**: четыре шага от Diasoft до созданного инцидента.
* Справа — инцидент и ИТ-услуга. Главное действие одно — «Открыть инцидент».

## 6.3. Дашборд «Диво Мера»

![Дашборд](../figma-plugin/preview/03-Дашборд-Диво-Мера.png)

* Четыре KPI: доступность против цели, инциденты, время обнаружения и восстановления.
* **Состояние услуг**: статус сейчас, доступность и полоса 30 дней — цвет дня показывает худший уровень событий.
* Кольцо событий за месяц по уровням.

## 6.4. Виджет на «Диво Портале»

![Виджет](../figma-plugin/preview/04-Виджет-Диво-Портал.png)

Пользователь бэк-офиса видит **«Известная проблема»** с номером инцидента и сроком решения и статусы
всех казначейских услуг. Это снижает число дублирующих обращений во время сбоя.

## 6.6. Как открыть макеты в Figma

1. Figma Desktop → новый пустой design-файл.
2. **Plugins → Development → Import plugin from manifest…** → [`figma-plugin/manifest.json`](../figma-plugin/manifest.json).
3. **Plugins → Development → «Диво × Diasoft · UI Kit»** — появятся страницы «Основы», «Компоненты», «Экраны».

## 6.7. Принципы

* Монохром и смысловой цвет: цвет есть только у шкалы критичности и статусов.
* Красный дозирован: только CRITICAL и нарушенный SLA.
* Число — главное: «осталось 22 мин» важнее, чем «дедлайн 20:00».
* Тишина — не норма: без heartbeat статус услуг «Нет данных».
* Цвет никогда не единственный носитель смысла: у каждого бейджа есть текст.
