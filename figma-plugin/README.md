# Диво × Diasoft · UI Kit — генератор для Figma

Плагин за один запуск собирает в пустом файле Figma UI Kit раздела «Диво» для событий из
Diasoft FA# Treasury.Back: переменные, стили текста, компоненты с вариантами и четыре экрана.

**Устройство кита** — как у генератора «ФОЛК»: примитивы → семантические токены → размеры,
компоненты с вариантами и свойствами, три страницы, всё на auto-layout.
**Визуальный язык** — как у дашборда деградаций сервисов: белая страница, чёрный текст, тонкие линии,
белые «таблетки» с тенью, серые подложки, шкала зелёный → жёлтый → оранжевый → красный, ячейки «тон / цвет».

## Как запустить

1. Откройте **десктопное приложение Figma**: плагины в разработке запускаются только в нём.
2. Создайте пустой design-файл.
3. Меню → **Plugins → Development → Import plugin from manifest…** → выберите `manifest.json` из этой папки.
4. Меню → **Plugins → Development → Диво × Diasoft · UI Kit**. Через 10–30 секунд внизу появится «✅ … готов».

Повторный запуск в том же файле спросит подтверждение и пересоздаст кит; ваши фреймы плагин не трогает.

**Шрифт.** Плагин берёт первый доступный из списка `FONT_FAMILIES`: Styrene A LC (как в дашборде
деградаций, если установлен), затем **Onest** (Google Fonts, есть в Figma), Manrope, Inter.

## Что появится

**Переменные** (3 коллекции, 74 шт.)
- `Диво × Diasoft · Примитивы` — нейтральные, зелёный, жёлтый, оранжевый, красный, синий.
- `Диво × Diasoft · Токены` — `color/bg/*`, `color/text/*`, `color/line/*`, роли шкалы
  `ok | warning | major | critical | info` с оттенками `default · strong · muted · subtle`.
- `Диво × Diasoft · Размеры` — `spacing/2xs…2xl`, `radius/xs…full`.

**Стили текста:** `Диво × Diasoft/…`, 11 стилей; основные размеры 24 · 15 · 12, как в дашборде деградаций.

**Страницы**
- **Основы** — обложка, палитра, токены, типографика, шкала критичности, отступы и скругления, принципы.
- **Компоненты** (75): иконки; кнопка (Основная · Контур · Таблетка · Призрачная); кнопка с иконкой;
  переключатель и переключатель темы; список; критичность (Тон · Заливка × 4 уровня); статус услуги;
  состояние события; заголовок и ячейка степени (Тон · Цвет); карточка KPI; статус интеграции;
  строка легенды; пункт хронологии; строка и заголовок таблицы событий; шапка (Сервис · Мера).
- **Экраны:**
  - **01 · Мониторинг событий** — шапка, фильтры, статус интеграции, кольцо активных событий,
    полосы по услугам, ключевые показатели, таблица событий;
  - **02 · Карточка события** — окно поверх мониторинга: шкала «норматив → дедлайн SLA», показатели,
    хронология, ИТ-услуга и инцидент, действия;
  - **03 · Дашборд «Диво Мера»** — KPI, кольцо событий за месяц, инциденты по услугам,
    детализация «тон / цвет» по уровням и полоса 30 дней;
  - **04 · Виджет «Диво Портал»** — известная проблема и статусы услуг для бэк-офиса.

## Превью без Figma

PNG в [`preview/`](preview) сгенерированы из **этого же** `code.js` эмулятором Figma Plugin API
([`tools/figma-preview/render.js`](../tools/figma-preview/render.js)). Эмулятор поддерживает переменные,
стили, компоненты и варианты, переводит auto-layout во flexbox и рендерит через Chromium. Он проверяет
то же, на чём падает Figma: шрифт загружен до текста, FILL только у детей auto-layout, нельзя добавлять
слои в экземпляр, свойства экземпляра существуют, все символы есть в шрифте, текст не вылезает из блока.

```bash
cd tools/figma-preview && npm install && node render.js
```

## Если у вас план Starter
- В переменных один режим, поэтому кит без тёмной темы.
- В файле не больше трёх страниц — киту их ровно хватает. Если страниц уже три, всё ляжет на первую.
